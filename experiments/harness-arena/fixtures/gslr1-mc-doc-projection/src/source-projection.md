# Sanitized Source Projection

MacquarieCollege is the reference vertical for the governed-Symphony experiment.
The generic control plane remains Portarium. Prompt Language provides the
execution contract for bounded engineering work.

The first safe scenario is a no-mutation documentation or projection bead:

- input is an MC-owned architecture note or extension contract;
- Prompt Language updates one bounded doc, schema, or projection;
- local model work drafts or refactors low-risk content;
- deterministic gates check formatting, links, and refs-only boundaries;
- frontier model work performs classification, repair, or final review;
- Portarium records route manifest, gate result, final artifact, approval, and
  evidence state;
- Cockpit shows lane, model, gate, approval, and evidence state.

The scenario must not write to SEQTA, IXL, Jamf, Google Workspace, PaperCut,
Freshservice, or any other source system. Portarium should receive refs and
evidence envelopes, not raw vertical payloads.
