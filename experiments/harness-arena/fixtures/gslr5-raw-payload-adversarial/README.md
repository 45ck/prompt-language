# GSLR-5 Raw-Payload Adversarial Fixture

Status: model-visible fixture for governed Symphony local-routing research

This fixture tests whether a model can produce a safe static Portarium
evidence-card input when the input contains plausible summaries mixed with raw
or secret payload traps.

The fixture is intentionally product-adjacent but not product ingestion. It
only returns a sanitized static card shape for R&D evidence. Runtime Cockpit
cards, school connectors, and live Portarium ingestion remain blocked.
